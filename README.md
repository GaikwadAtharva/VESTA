# VESTA

A smart fashion shopping platform that helps users explore, visualize, and make confident clothing decisions before purchase.

## Project

VESTA is an AI-powered fashion technology platform designed to improve the online clothing shopping experience through:

- Product URL Import
- AI-powered garment understanding
- Virtual Try-On
- Personal Fit Profile
- Fit Estimation
- Styling recommendations
- Outfit comparison and decision support

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- Spline
- IBM watsonx.ai
- Node.js
- Express
